# Inventory Management System

Sistema de gestión de inventario desarrollado en C# con conexión a SQL Server.

## Tecnologías
- C# .NET
- SQL Server
- ADO.NET
- appsettings.json para configuración

## Arquitectura
- **Entidades:** Clases del dominio y lógica de negocio
- **Vistas:** Interfaz de usuario por consola
- **Data:** Gestión de conexión a base de datos

## Funcionalidades
- Agregar productos
- Listar productos
- Buscar producto por Id
- Actualizar producto
- Eliminar producto

## Configuración
Copia `appsettings.example.json` a `appsettings.json` y configura tu string de conexión.
